Vorance

Mobile cycling logbook app built with FlutterFlow and Firebase.

Year : 2025
FlutterFlowFirebaseGoogle MapsFlutterFlowFirebaseGoogle MapsFlutterFlowFirebaseGoogle Maps

ABOUT

The Project

Overview

Individual university project driven by my passion for cycling. The app uses Firebase for authentication and data persistence, the Google Maps API for route visualisation, and Custom Functions for automatic average speed calculation (V=D/T). All validation criteria were met during the final acceptance testing.

Core Features

Manual ride logging (distance, duration, elevation, feeling). Automatic average speed calculation via Custom Function. Route visualisation on map via city geocoding. Firebase authentication and Firestore persistence. Light/dark mode with global App State management.
